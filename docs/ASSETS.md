## Regenerating the placeholders

The 83 files under `public/images/` are produced by one deterministic script (sharp, SVG to WebP). It only
rewrites a file when its bytes change, so running it twice leaves the tree untouched:

```
node scripts/generate-placeholders.mjs
```

The product, colour and hex lists live in `scripts/placeholder-manifest.mjs`; a unit test
(`tests/unit/data/invariants.test.ts`) checks that they match `src/data/products.ts` and that every image
referenced by the data exists with the recorded width and height. Replace these files with rights-cleared
photography before any public marketing use (RULES 14.3).
