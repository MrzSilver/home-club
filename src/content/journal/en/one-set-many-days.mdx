## Build around four pieces

Start with a top, a bottom, a cap and socks. Think of them as a starting point for an outfit rather than a rule about what you have to wear.

## Change one thing

Try a different colour for the top while keeping the other pieces. Then try a different fit for the bottom. Small changes can make it easier to decide which combination feels right.

## Check the whole set

Our demo Look Builder lets you choose a colour and size for each slot. Check availability before adding. The set discount appears in the cart while a complete set is present; remove a required piece and the price is recalculated.
